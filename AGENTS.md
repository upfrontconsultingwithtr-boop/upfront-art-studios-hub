# Naming and review

- Use **Upfront Art Studio** for the public website, app, install labels, and new public materials.
- Use **Creative Command Hub** for the private dashboard. Keep the dashboard off the public website.
- Preserve existing storage keys and app identifiers when updating display names so earlier saved work remains accessible.
- For review items, lead with a screenshot, mockup, or a direct link to a working preview and label its status clearly.
